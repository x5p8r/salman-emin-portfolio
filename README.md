# Salman Emin Portfolio

A responsive, bilingual portfolio built with plain HTML, CSS, JavaScript, and a small native WebGL hero object.

## Features
- Charcoal structure, metallic silver details, and restrained acid-lime accents
- English and Arabic language toggle (saved in localStorage)
- RTL layout support for Arabic
- Separate Home, Work, Expertise, About, and Contact pages
- Geometric hero composition with a metallic WebGL torus and CSS fallback
- Cut-metal triangle signature across the homepage and Flux preview, with an interactive three-skill diagram on Expertise
- Subtle desktop-only project-card tilt, layered surfaces, and tactile controls
- Project presentations for Flux, ServX, and HTML Generator
- Actual Flux, ServX, and HTML Generator website screenshots in portfolio previews
- Reduced-motion support and keyboard-visible focus states
- Responsive navigation for mobile

## Run locally
Open `index.html` in a browser. No build step or dependencies are required. Google Fonts are loaded remotely; system fallback fonts are provided. If WebGL is unavailable, the hero ring uses its CSS material treatment.
